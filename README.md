# Noah WordPress Theme v2.0

This repo includes a redesigned Noah luxury storefront theme with a WordPress theme settings panel and a one-click demo import for the main storefront pages inspired by the design mockups in the repository.

## Included

- `noah-theme/` – WordPress theme folder
- Full storefront homepage matching the Noah luxury jewelry brand style
- Customizer-based theme controls for accent color, background color, text color, phone, and email
- Theme options page under Appearance > Noah Theme Settings
- One-click demo import for multiple storefront pages including:

  - Search Results
  - Custom Design

## How to use

1. Copy `noah-theme` into `wp-content/themes/` in your WordPress install.
2. Activate the `Noah Theme` in Appearance > Themes.
3. Install Elementor Pro for advanced page editing.
4. Open Appearance > Noah Theme Settings and click "Run Demo Import".
5. Open Appearance > Customize to edit global colors and contact details.

## Note

This version is designed to provide a complete luxury storefront structure and a full-page demo import foundation based on the provided Figma references. For a true pixel-perfect match to each screenshot, Elementor Pro can be used to fine-tune each design block and replace the global starter sections with exact image-based page layouts.
